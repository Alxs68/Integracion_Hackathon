# Interfaz Web - Equipo G68

Aquí están los archivos de la página web que verán los usuarios. Queremos que sea bonita, fácil de usar y rápida.

## 🎨 ¿Cómo está hecha?

- **Diseño**: Simple y limpio. Tiene modo oscuro y claro porque a todos nos gusta el modo oscuro.
- **Gráficos**: Usamos `Chart.js` para mostrar los datos de forma visual.
- **Tecnología**: HTML, CSS y JavaScript puro (sin frameworks pesados innecesarios).

## 📁 Archivos Importantes

- `index.html`: El esqueleto de la página.
- `style.css`: Los estilos para que se vea bien (colores, fuentes, espacios).
- `app.js`: El cerebro de la página web. Se encarga de hablar con el servidor y pintar los gráficos.

## 🔗 ¿Cómo se conecta?

La página web le pide datos al servidor usando rutas simples como `/api/stats`. Así es más fácil de mantener y funciona en cualquier lado.
