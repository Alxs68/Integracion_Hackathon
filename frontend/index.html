🔬 Funcionamiento del Motor Híbrido G68

El motor de análisis de sentimiento G68 utiliza un enfoque híbrido de dos capas para maximizar la precisión:

  • Capa 1 (Estadística): Un modelo Bi-LSTM (Long Short-Term Memory) entrenado con un corpus masivo procesa la estructura gramatical y el contexto global de la frase.
  • Capa 2 (Veto y Heurística): Un sistema de reglas de negocio busca términos críticos predefinidos. Si se detectan conceptos de alta gravedad (problemas de higiene, seguridad o estafas), el motor puede aplicar un "Veto de Negatividad", garantizando que las alertas no pasen desapercibidas.
  • Explicabilidad: El motor extrae "Top Features" que resaltan las palabras exactas que inclinaron la balanza del sentimiento, permitiendo una trazabilidad total.

Contrato de Integración: 

POST /predict/sentiment
{
  "text": "..."
}
→ { "prevision": "Negativo", "probabilidad": 0.99, "top_features": ["suciedad", "local"] }
