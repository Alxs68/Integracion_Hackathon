🔬 Funcionamiento del Motor Híbrido G68

El motor de análisis de sentimiento G68 utiliza un enfoque híbrido de dos capas para maximizar la precisión:

  • Capa 1 (Estadística): Un modelo Bi-LSTM procesa la estructura gramatical y el contexto global.
  • Capa 2 (Veto Semántico): Un sistema de reglas que busca términos críticos. Si se detectan, el motor aplica un "Veto de Negatividad", forzando valores de confianza específicos.

🎯 Origen de las Probabilidades (Confianza)

Los valores de confianza dependen de qué capa tome la decisión final en el motor G68:

  • 99% (Capa Semántica): Casos de alta prioridad detectados por el sistema de Veto (Higiene, Estafa, Seguridad).
  • 85% (Capa Semántica): Reemplazo de sentimiento decidido por heurística sobre la predicción del modelo.
  • 50% (Capa Semántica): Forzado de neutralidad cuando el texto es ambiguo o carece de carga sentimental clara.
  • Valores Dinámicos: Si no interviene la capa semántica, se muestra la probabilidad original del modelo Bi-LSTM (ej. 76.4%, 58.2%), lo que indica el grado de certeza estadística puro.
