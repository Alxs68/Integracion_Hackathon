# Plan de Aprendizaje: De la Teoría a la Práctica (Datos & MIPYMES)

Este documento sirve como hoja de ruta para pasar de conocimientos teóricos de bases de datos a un manejo ágil y prolijo orientado al mercado de las MIPYMES.

## 🎯 Objetivo General
Convertirse en un perfil técnico visible y prolijo, capaz de resolver situaciones cotidianas de negocio mediante datos.

---

## 🚀 Hoja de Ruta (4 Fases)

### 1. El "Salvavidas" Digital (Estructura y Limpieza)
*   **Problema:** Desorden informativo (Excels dispersos).
*   **Proyecto:** Almacén de Datos Centralizado.
*   **Habilidades:** SQL (Joins, Normalización), Python (Pandas/ETL).
*   **Entregable:** Un script de limpieza y un esquema de DB impecable.

### 2. Análisis de Supervivencia (Reportabilidad Ágil)
*   **Problema:** Desconocimiento de métricas de crecimiento.
*   **Proyecto:** Dashboard de Salud Financiera.
*   **Habilidades:** SQL Avanzado (CTEs, Window Functions), Streamlit/PowerBI.
*   **Entregable:** Reporte de KPIs críticos (MoM, Ticket promedio).

### 3. Escuchar al Cliente (IA Aplicada)
*   **Problema:** Feedback negativo no detectado a tiempo.
*   **Proyecto:** Monitor de Reputación (Usando tu API G68).
*   **Habilidades:** Integración de APIs, Alertas en BD, Análisis de Texto.
*   **Entregable:** Dashboard de sentimiento con alertas para comentarios críticos.

### 4. Visibilidad y Prolijidad (Marca Personal)
*   **Problema:** "Nadie sabe lo que sé hacer".
*   **Estrategia:** 
    *   Documentación profesional (READMEs).
    *   Casos de estudio en LinkedIn (Enfoque en solución de negocio).
    *   Código limpio y estructurado.
